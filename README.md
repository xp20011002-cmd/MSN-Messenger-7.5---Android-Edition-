# MSN Messenger 7.5 — Android Edition

🦋 **Bringing the classic MSN Messenger 7.5 experience to Android!**

MSN Messenger 7.5 — Android Edition is an independent Android project inspired by the legendary instant messaging application.

The goal is to recreate the classic MSN Messenger experience on modern Android devices, featuring a nostalgic interface and experimental connectivity with the Escargot Messenger network.

## ✨ Features

- 🎨 Classic MSN Messenger 7.5-inspired interface
- 🔐 Email and password sign-in screen
- 🟢 Online status selection
- 💾 Remember Me and Remember My Password options
- 🌐 Experimental Escargot network connectivity
- 👥 Contact list interface
- 📱 Android support

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| Kotlin | Application development |
| Android SDK | Android platform |
| Gradle | Build automation |
| XML | User interface layouts |
| MSN Protocol (MSNP) | Legacy messaging protocol |
